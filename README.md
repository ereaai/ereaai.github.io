# ereaai.com

Erea AI website and app links, hosted free on GitHub Pages.

- `/` - website (index.html, site.css)
- `/privacy`, `/terms`, `/sms-opt-in` - legal pages (same text as the Twilio-registered pages on ereai.carrd.co)
- `/book?b=<booking id>&n=<studio name>` - client booking page, no Google banner. Add `&checkin=1` for the door QR.
- `/desk?s=<studio key>` - staff Front Desk launcher (installable app)
- `/help` - Erea Help Desk
